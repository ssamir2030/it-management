# IT Asset Mobile App

تطبيق جوال لنظام إدارة أصول تقنية المعلومات

## 🚀 التشغيل

```bash
# تشغيل التطبيق
npm start

# تشغيل على الويب
npm run web

# تشغيل على Android
npm run android

# تشغيل على iOS
npm run ios
```

## 📱 الميزات

- ✅ تسجيل الدخول
- ✅ لوحة التحكم
- ✅ عرض الأصول
- ✅ مسح الباركود
- ✅ التذاكر والطلبات
- ✅ الإشعارات
